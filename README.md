# EchoWane

EchoWane is a High-Performance, real-time video processing engine for on-demand data analysis and rendering on a cloud-based platform.

EchoWane is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/EchoWane.git`
2. `cd EchoWane`
3. Install in editable mode: `pip install -e .`

## Configuration

EchoWane is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
